💻 C++ 기초 핵심 정리 (개발 환경 구축부터 제어문까지)

💡 한 줄 요약: C++ 개발 환경(VS Code, MSYS2 컴파일러) 구축부터 입출력, 변수·배열, 연산자, 조건문·반복문까지 핵심 기초 문법

1. C++ 소개 및 개발 환경 구축

  • C++ 특징: 기계어로 직접 컴파일되어 실행 속도가 매우 빠르며, 하드웨어(메모리 등)에 직접 접근할 수 있는 고성능 언어입니다. 임베디드, 게임 엔진, OS/드라이버, 고성능 컴퓨팅, 금융, 딥러닝 프레임워크(PyTorch, TensorFlow 코어), 로보틱스(ROS) 등에 활용됩니다.
  • C vs C++ 주요 차이점:
    • 객체지향 패러다임: C에는 클래스(class)와 객체지향(OOP) 개념이 없지만 C++은 이를 지원합니다.
    • 자원 관리: C는 malloc과 free로 직접 메모리를 확보하고 해제해야 합니다.
    • 타입 안정성: C++은 템플릿과 auto 등을 통해 컴파일 시점에 더 엄격한 타입 검사를 수행합니다.
  • IDE & 컴파일러 설치:
    • VS Code: 코드 에디터, 컴파일러, 디버거 기능을 통합 지원하는 무료 IDE로, 설치 시 반드시 PATH에 추가 옵션을 선택해야 합니다.
    • GCC / G++: gcc는 C/C++를 구분해 컴파일하며 C++ 표준 라이브러리를 자동 연결하지 않지만, g++는 .c 파일도 C++로 취급하고 링크 시 C++ 표준 라이브러리를 자동 연결합니다.
    • 환경 변수 설정: MSYS2 UCRT64에서 pacman -S mingw-w64-ucrt-x86_64-gcc로 설치한 후, Windows 시스템 환경 변수 Path에 C:\msys64\ucrt64\bin을 추가합니다.
  • 컴파일 및 실행 과정:
    • 컴파일 명령어 g++ test.cpp (또는 실행 파일명 지정 시 g++ test.cpp -o test.exe)를 입력하면 전처리(Preprocessing) → 컴파일(Compile) → 어셈블리(Assembly) → 링크(Link) 4단계를 거쳐 실행 파일이 생성됩니다.

2. 출력 (Output)

C++

C++ 코드

  • #include <iostream>: 표준 입출력 헤더 파일을 불러오는 전처리 지시자입니다.
  • using namespace std;: 표준 라이브러리의 std 네임스페이스를 생략하게 해주며, 큰 프로젝트에서는 이름 충돌 방지를 위해 std::cout 형태로 쓰는 것이 권장됩니다.
  • int main(): 프로그램의 진입점이며, 관례상 0 반환은 정상 종료를 의미합니다(생략 시 컴파일러가 자동 추가).
  • cout <<: 데이터를 표준 출력 스트림으로 보내며, 줄바꿈은 자동 처리되지 않으므로 개행 문자('\n')를 직접 넣어야 합니다.

3. 변수와 데이터 타입 (Variables)

  • 선언과 초기화: 변수 선언(int age;) 시 메모리 공간이 확보되고 기존 잔여 데이터인 쓰레기값이 들어 있으며, 대입 연산자(=)로 값을 넣는 과정을 초기화(int height = 135;)라고 합니다.
  • 변수명 규칙: 영문 대소문자, 숫자, 언더스코어(_)만 사용 가능하며 숫자로 시작하거나 예약어(if, for 등)를 쓸 수 없고, 관례상 camelCase를 사용합니다.
  • 주요 데이터 타입 요약:
타입크기표현 범위 / 특징
bool1바이트 true / false (기본적으로 1과 0으로 표현)
char1바이트 -128 ~ 127 (정수 대입 시 ASCII 문자로 변환 출력)
short2바이트 -32,768 ~ 32,767
int4바이트 약 -21억 ~ 21억 (unsigned int는 0 ~ 약 42억)
long long8바이트 약 $-9.2 \times 10^{18} \sim 9.2 \times 10^{18}$
float / double4바이트 / 8바이트 실수형 (유효자리 약 6~7자리 / 약 15~16자리)

4. 배열 (Array)

  • 개념 및 인덱싱: 같은 자료형의 변수들을 연속된 메모리에 나열한 자료구조로, 0번부터 크기 - 1번까지의 인덱스로 빠르게 접근합니다.
  • 초기화: int arr[10] = {0,};처럼 일부만 초기화하면 나머지 요소는 자동으로 0으로 채워집니다.
  • 주의사항: 배열 범위를 벗어난 양수 인덱스에 접근해도 컴파일 에러가 발생하지 않고 인접 메모리의 쓰레기값을 읽어오므로 주의해야 합니다.

5. 입력 (Input)

  • 기본 입력: cin >> a;를 통해 공백이나 줄바꿈(\n) 단위로 구분하여 데이터를 입력받습니다.
  • 예외 처리(C++11 기준): 자료형과 맞지 않는 값을 입력하면 0이 대입되며, int 범위를 초과하는 큰 정수를 입력하면 해당 자료형의 최댓값(INT_MAX, 2147483647)이 대입됩니다.
  • Windows 콘솔 한글 깨짐 해결: <windows.h> 헤더를 추가하고 SetConsoleOutputCP(CP_UTF8); 및 SetConsoleCP(CP_UTF8);를 호출합니다.

6. 연산자 (Operators)

  • 산술 연산자: +, , , / (정수 나눗셈은 몫 반환), % (나머지 반환)
  • 비교 연산자: ==, !=, >, <, >=, <= (결과를 불리언으로 반환)
  • 논리 연산자: && (AND, 모두 참일 때 참), || (OR, 하나라도 참이면 참), ! (NOT, 결과 반전)
  • 혼합 대입 & 증감 연산자: +=, =, =, /=, %=로 연산과 대입을 동시에 수행하며, 전위(++a)는 증감 후 사용, 후위(a++)는 사용 후 증감합니다.

7. 조건문 (Conditionals)

  • 구조: if, else if, else를 사용해 조건의 참/거짓에 따라 실행 흐름을 분기하며, 실행 코드가 1줄일 경우 중괄호({})를 생략할 수 있습니다.
  • 자주 하는 실수 3가지:
    1. 비교(==) 대신 대입(=) 연산자 사용
    2. 범위 비교 시 1 <= a <= 10처럼 작성 (반드시 1 <= a && a <= 10으로 작성해야 함)
    3. 다중 값 비교 시 나열 작성 (반드시 a == 1 || a == 2처럼 ||로 연결해야 함)

8. 반복문 (Loops)

  • for 문: for(초기식; 조건식; 증감식) 형태로 주로 반복 횟수가 정해져 있을 때 사용합니다.
  • while 문: while(조건) 형태로 특정 조건을 만족할 때까지 반복할 때 주로 사용합니다.
  • 제어 키워드:
    • break: 반복문을 즉시 종료하고 탈출합니다.
    • continue: 아래 코드를 건너뛰고 다음 반복 회차로 넘어갑니다 (while 문에서 증감식보다 앞에 위치하면 무한 루프에 빠질 수 있으므로 주의해야 합니다).
