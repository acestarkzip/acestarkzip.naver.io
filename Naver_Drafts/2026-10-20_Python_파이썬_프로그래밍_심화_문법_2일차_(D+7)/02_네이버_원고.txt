📃 a. OOP (객체지향 프로그래밍)

• OOP : 데이터와 기능을 하나의 객체로 묶어 프로그램을 설계하는 방식
• Class (클래스) : 객체를 만들기 위한 설계도
• Instance (인스턴스) : 클래스를 기반으로 생성한 실제 객체
• Attribute (속성) : 객체가 가지는 데이터
• Method (메서드) : 객체가 수행하는 기능

```plain text
class Robot:
    def __init__(self, name):
        self.name = name

    def move(self):
        print(f"{self.name} is moving")

robot = Robot("R1")
robot.move()  # R1 is moving
```

• class : 클래스 정의
• __init__() : 인스턴스 생성 시 초기화
• self : 메서드가 호출된 인스턴스 자신
• robot : Robot 클래스로 생성한 인스턴스

📃 주요 OOP 개념

개념 | 의미 | 예시
상속 (Inheritance) | 기존 클래스의 속성과 기능을 물려받음 | class Dog(Animal):
다형성 (Polymorphism) | 같은 메서드 호출이 객체에 따라 다르게 동작 | dog.speak()
캡슐화 (Encapsulation) | 데이터와 기능을 묶고 내부 구현에 대한 직접 접근을 관리 | _value, __value
추상화 (Abstraction) | 핵심 기능만 외부에 노출하고 세부 구현을 감춤 | move() 인터페이스

1. 상속 (Inheritance)

기존 클래스의 기능을 재사용하고 확장하는 개념

```plain text
class Animal:
    def speak(self):
        print("소리를 냅니다.")

class Dog(Animal):
    pass

dog = Dog()
dog.speak()
```


2. 다형성 (Polymorphism)

같은 메서드 이름을 사용해도 객체에 따라 다른 결과를 낼 수 있는 개념

```plain text
class Dog:
    def speak(self):
        print("멍멍")

class Cat:
    def speak(self):
        print("야옹")

for animal in [Dog(), Cat()]:
    animal.speak()
```


3. 캡슐화 (Encapsulation)

객체 내부의 데이터를 보호하고 정해진 메서드를 통해 접근하도록 설계하는 개념

```plain text
class Robot:
    def __init__(self):
        self.__battery = 100

    def get_battery(self):
        return self.__battery

robot = Robot()
print(robot.get_battery())  # 100
```

※ __battery는 이름 변경(Name Mangling)이 적용되어 직접 접근이 제한되지만, 완전한 보안 기능은 아닙니다.

4. 추상화 (Abstraction)

공통적으로 필요한 기능의 형태를 정의하고, 실제 동작 방식은 하위 클래스에서 구현하는 개념

```plain text
from abc import ABC, abstractmethod

class Robot(ABC):
    @abstractmethod
    def move(self):
        pass

class WheeledRobot(Robot):
    def move(self):
        print("바퀴로 이동합니다.")

robot = WheeledRobot()
robot.move()
```

• ABC : 추상 클래스 정의에 활용
• @abstractmethod : 하위 클래스에서 구현해야 하는 메서드 지정
