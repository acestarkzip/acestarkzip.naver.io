📃 a. Sequence Data (시계열 데이터의 구조와 특징)

Sequence Data (순차 데이터)

  • 데이터가 특정한 순서에 따라 나열된 형태이다.
  • 이전 데이터가 현재 데이터에 영향을 줄 수 있다.
  • 예시: 문장, 음성, 주가, 날씨, 센서 데이터

Time Series Data (시계열 데이터)

  • 시간의 흐름에 따라 수집된 데이터이다.
  • Sequence Data의 한 종류이다.

주요 특징

특징설명
순서 의존성데이터의 순서가 중요함
시간적 의존성과거 데이터가 현재에 영향을 줌
가변 길이데이터마다 길이가 다를 수 있음
시간적 패턴추세, 계절성, 순환성 등이 존재

활용 분야: 주가 예측, 날씨 예측, 음성 인식, 서버 자원 사용량 예측

순차 데이터의 관계를 효과적으로 학습하기 위해 다양한 모델이 발전했다.

모델등장 배경 및 특징

핵심: RNN에서 시작하여 LSTM, GRU, Attention, Transformer로 발전했다.

📃 c. SimpleRNN의 구조와 모델학습

RNN (Recurrent Neural Network)

  • 이전 시점의 정보를 현재 시점으로 전달하는 순환 신경망이다.
  • 순차 데이터의 시간적 관계를 학습한다.

주요 구성 요소

구성 요소설명
Input현재 입력 데이터
Hidden State이전 정보를 저장하고 전달하는 내부 상태
Weight학습에 사용되는 가중치
Output모델의 예측 결과

작동 과정

  1. 현재 입력 데이터 전달
  2. 이전 Hidden State 전달
  3. 두 정보를 결합하여 계산
  4. 새로운 Hidden State 생성
  5. 다음 시점으로 정보 전달

주요 특징

  • 시간 단계마다 동일한 가중치 사용 (Weight Sharing)
  • BPTT(Backpropagation Through Time)를 이용한 역전파 학습
  • 순차 데이터의 패턴 학습

입력 데이터 구조 (PyTorch)

(Batch Size, Sequence Length, Input Features)

항목설명
Batch Size한 번에 학습하는 데이터 개수
Sequence Length하나의 데이터에 포함된 시간 단계
Input Features시간 단계마다 입력되는 변수 개수

📃 d. 장기 문맥과 Gated RNN (장기 의존성 문제와 극복 배경)

Long-Term Dependency (장기 의존성)

  • 오래전의 정보가 현재 결과에 영향을 주는 현상이다.
  • 기존 RNN은 긴 시퀀스에서 과거 정보를 유지하기 어렵다.

주요 문제점

문제설명
Vanishing Gradient역전파 과정에서 기울기가 지나치게 작아짐
Exploding Gradient역전파 과정에서 기울기가 지나치게 커짐

BPTT (Backpropagation Through Time)

  • RNN의 시간 방향으로 오차를 역전파하는 학습 방식이다.

Gated RNN (게이트 기반 RNN)

  • Gate를 통해 정보를 기억하거나 제거하는 구조이다.
  • 장기 의존성 문제를 완화하기 위해 개발되었다.
  • 대표 모델: LSTM, GRU

📃 e. LSTM (Long Short-Term Memory)

LSTM이란?

  • 기존 RNN의 장기 의존성 문제를 완화하기 위해 개발된 순환 신경망이다.
  • 1997년 제안되었다.
  • Cell State와 Gate를 이용해 정보를 선택적으로 기억한다.

주요 구성 요소

구성 요소역할
Cell State장기 기억 정보 전달
Hidden State현재 시점의 정보 전달
Forget Gate불필요한 기존 정보 제거
Input Gate새로운 정보 저장
Output Gate외부로 전달할 정보 결정

LSTM의 작동 과정

  1. Forget Gate: 기존 정보 중 버릴 내용 결정
  2. Input Gate: 새로운 정보 중 저장할 내용 결정
  3. Cell State: 기존 기억과 새로운 정보 업데이트
  4. Output Gate: 현재 기억 중 출력할 정보 결정
  5. Hidden State: 새로운 상태 생성

핵심: 중요한 정보는 기억하고 불필요한 정보는 잊도록 학습하는 구조이다.

📃 f. RNN variants (다양한 확장 구조)

기본 RNN의 단점을 보완하거나 특정 작업에 적합하도록 발전한 구조이다.

모델핵심 특징
SimpleRNN기본적인 순환 신경망
LSTM3개의 Gate와 Cell State 활용
GRU2개의 Gate를 사용하는 간소화된 구조
Bidirectional RNN과거와 미래 양방향 정보 활용
Stacked RNN여러 RNN 계층을 쌓은 구조
Encoder-Decoder입력 시퀀스를 출력 시퀀스로 변환
Attention중요한 정보에 집중
TransformerSelf-Attention 기반 정보 처리

주요 개념

  • GRU: LSTM보다 구조가 단순하며 별도의 Cell State를 사용하지 않는다.
  • Bidirectional RNN: 양방향의 문맥 정보를 함께 활용한다.
  • Stacked RNN: 여러 계층을 연결하여 복잡한 특징을 학습한다.
  • Encoder-Decoder: 번역과 같은 시퀀스 변환 작업에 활용한다.
  • Attention: 중요한 입력 정보에 더 높은 가중치를 부여한다.
  • Transformer: RNN의 순환 구조 없이 Attention을 중심으로 처리한다.

💡 오늘의 핵심 학습 포인트

  1. RNN은 이전 정보를 기억하여 다음 데이터 처리에 활용한다.
  2. 기존 RNN은 긴 시퀀스에서 기울기 소실 문제가 발생할 수 있다.
  3. LSTM과 GRU는 Gate를 이용하여 정보의 흐름을 조절한다.
  4. Transformer는 순환 구조 대신 Attention을 활용한다.

최종 목표: 순차 데이터가 무엇인지 이해하고, RNN에서 Transformer까지 발전한 이유와 각 모델의 차이를 설명할 수 있어야 한다.
