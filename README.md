# SSS Robotics | Notion → Naver Blog Draft Automation

Notion 데이터베이스에서 **한국시간 기준 오늘 날짜**의 게시글을 읽어 네이버 블로그에 옮기기 쉬운 원고와 이미지 파일을 자동 생성합니다.

## 동작 원칙

- 네이버 블로그 편집기에서 지원하지 않는 Notion 전용 서식을 그대로 복제하지 않습니다.
- TXT는 단순 텍스트 원고이며, 글자 크기와 노란 강조가 필요한 경우 DOCX 서식 원고를 사용합니다.
- HTML은 미리보기 전용입니다. HTML에서 본문을 복사하지 마세요.
- 이미지는 `images/` 폴더에 본문 등장 순서대로 `이미지_01_...`, `이미지_02_...` 형식으로 저장합니다.
- 본문 DOCX의 이미지 삽입 안내는 노란색으로 강조되며, 이미지 파일명과 같은 번호를 사용합니다.
- 연락처 섹션은 Notion 원문에 있는 YouTube·홈페이지·이메일 텍스트 링크만 유지하며 별도 링크 카드 이미지는 생성하지 않습니다.
- GitHub Actions는 네이버에 로그인하거나 게시물을 발행하지 않습니다. 원고와 미디어만 준비하며, 최종 확인과 발행은 사용자가 직접 합니다.

## 자동 실행

- GitHub Actions: `.github/workflows/naver-blog.yml`
- 실행 주기: 매일 07:17 및 19:17 KST
- 수동 실행: Actions → Naver Blog Drafts → Run workflow
- `update_existing`을 체크하면 발행 완료 상태가 아닌 기존 초안도 다시 생성합니다.
- 현재는 테스트 모드로 한국시간 오늘 날짜에 해당하는 페이지만 조회합니다.

## GitHub Secrets

Repository Settings → Secrets and variables → Actions에 아래 두 값이 필요합니다.

- `NOTION_TOKEN`
- `NOTION_DATABASE_ID`

Notion 데이터베이스는 해당 Integration과 공유되어 있어야 합니다.

## Notion 속성 기본값

| 환경 변수 | 기본 속성명 | 용도 |
|---|---|---|
| `NOTION_PROPERTY_TITLE` | `제목` | 게시글 제목 |
| `NOTION_PROPERTY_DATE` | `날짜` | 오늘 날짜 필터 |
| `NOTION_PROPERTY_MEMO` | `간단메모` | 내부 관리 메모 |
| `NOTION_PROPERTY_TAGS` | `태그` | 내부 metadata 보관용이며 네이버 원고에는 자동 추가하지 않음 |

## 생성 파일

`Naver_Drafts/날짜_제목/` 아래에 생성됩니다.

| 파일 | 사용 목적 |
|---|---|
| `00_네이버_블로그_사용방법.txt` | 작업 순서 안내 |
| `01_네이버_제목.txt` | 네이버 제목란에 붙여넣을 제목 |
| `02_네이버_본문.txt` | 순수 텍스트 대체 원고 |
| `02_네이버_본문_서식.docx` | **서식 복사용 원고**: 제목 단계별 크기와 노란 이미지 안내 표시 |
| `03_이미지_목록.txt` | 이미지 번호와 파일명 목록 |
| `04_발행_체크리스트.txt` | 발행 전 점검 |
| `05_코드_원문.txt` | 코드 이미지의 원문 백업 (코드가 있을 때만 생성) |
| `06_미리보기.html` | 브라우저 미리보기 전용 |
| `07_이미지_전체.zip` | 모든 이미지를 한 번에 내려받기 위한 묶음 파일 |
| `images/` | 본문 순서대로 번호가 붙은 이미지 |
| `metadata.json` | Notion 페이지 ID 및 내부 처리 정보 |

## 네이버 블로그에 옮기는 방법

1. GitHub에서 해당 초안 폴더를 다운로드하고 압축을 풉니다.
2. `01_네이버_제목.txt`에서 제목을 복사해 네이버 제목란에 붙여넣습니다.
3. 글자 크기와 노란 이미지 표시를 적용하려면 `02_네이버_본문_서식.docx`를 Word에서 엽니다. 본문 전체를 복사해 네이버 편집기에 붙여넣습니다.
4. 제목 크기는 원본 제목 단계 기준으로 `#` 30pt, `##` 28pt, `###` 24pt, `####` 19pt이며, 일반 본문은 15pt입니다. 글꼴·크기·강조가 네이버 편집기에 어떻게 반영되는지 붙여넣은 후 확인하세요.
5. 노란색으로 표시된 `이미지 NN 삽입 위치` 문구를 지우고, 같은 번호의 이미지를 첨부합니다.
6. 이미지는 `07_이미지_전체.zip` 하나를 내려받아 압축을 풀면 한 번에 준비됩니다.
7. 압축을 푼 이미지 파일을 네이버 사진 첨부 창에서 여러 장 선택하고, 파일명 번호와 `03_이미지_목록.txt` 순서에 맞춰 본문 위치에 배치합니다.
8. 연락처 섹션의 YouTube·Website·Email 텍스트 링크를 확인합니다. 별도 연락처 카드 이미지는 생성하지 않습니다.
9. `02_네이버_본문.txt`는 서식이 필요 없을 때 사용하는 대체본입니다. TXT 자체에는 글자 크기나 실제 노란색 배경이 저장되지 않습니다.
10. `06_미리보기.html`은 미리보기 전용입니다. 이 파일의 본문을 복사해 네이버에 붙여넣지 마세요.
11. 최종 미리보기 후 직접 발행합니다.

## 코드 이미지

코드는 한글 주석을 포함해 이미지로 만들며, 원문은 `05_코드_원문.txt`에 보존합니다. GitHub Actions는 `fonts-noto-cjk`를 설치하고, 로컬 환경에서는 설치된 한국어 지원 폰트를 탐색합니다.

## 설정 옵션

| 변수 | 기본값 | 설명 |
|---|---|---|
| `UPDATE_EXISTING_DRAFTS` | `false` | 이미 처리한 미발행 초안 갱신 |
| `MAX_DOWNLOAD_MB` | `50` | 파일당 미디어 다운로드 제한 |
| `CODE_FONT_PATH` | 자동 탐색 | 코드 이미지 폰트 경로를 강제 지정 |

## Public 저장소 주의
