# SSS Robotics | Notion → Naver Blog Draft Automation

Notion 데이터베이스에서 **한국시간 기준 오늘 날짜**에 해당하는 게시글만 확인해 네이버 블로그용 초안을 생성합니다. (현재 테스트 모드)

- 실행 환경: GitHub Actions (완전 클라우드 실행, 로컬 PC 불필요)
- 실행 주기: 매일 07:17 및 19:17 KST
- 기존 `notion-to-github` 저장소와 워크플로는 수정하지 않습니다.
- Notion 속성명 기본값: `제목`, `날짜`, `간단메모`, `태그`
- Notion 페이지 ID로 중복 생성 방지
- Notion API에서 오늘 날짜의 페이지만 조회하며, 본문/이미지도 해당 페이지에 대해서만 다운로드
- 처리 이력은 `Naver_Drafts/processed_pages.json`에 자동 저장
- 본문 제목은 H2/H3/H4로 정리하고, 제목을 추출해 클릭 가능한 목차를 자동 생성
- 빈 문단·빈 제목·빈 인용문·빈 이미지 캡션은 출력하지 않음
- Notion 토글은 접힌 상태 대신 제목과 내부 내용을 펼친 형태로 변환
- 코드 스크린샷은 한글 주석과 문자열을 지원하는 Noto CJK 폰트를 사용
- 이 저장소는 Public이므로 저장된 초안과 이미지도 공개됩니다.

## GitHub 설정

Repository Settings → Secrets and variables → Actions에 다음 두 Secret이 필요합니다.

- `NOTION_TOKEN`
- `NOTION_DATABASE_ID`

Notion 데이터베이스는 해당 Integration과 공유되어 있어야 합니다.

## 날짜 범위(테스트 모드: 오늘만)

한국시간 기준 오늘 날짜와 Notion `날짜` 속성이 일치하는 게시글만 조회합니다. 예를 들어 오늘이 2026-11-15라면 `날짜` 속성이 `2026-11-15`인 페이지에 한해 초안을 생성합니다.

날짜 필터는 Notion 데이터베이스 조회 API에 직접 전달하므로 다른 날짜의 페이지 메타데이터까지 전부 가져오지 않습니다. 반환된 페이지의 날짜도 Python 코드에서 한 번 더 확인합니다. 날짜 속성이 비어 있거나 오늘이 아닌 페이지는 처리하지 않습니다.

## 최초 실행

별도의 `seed_tracker.py` 또는 로컬 `.env` 설정이 필요하지 않습니다. 첫 GitHub Actions 실행부터 오늘 날짜의 게시글만 확인하고, 처리 이력을 자동 생성합니다. 따라서 과거 전체 게시글을 일괄 초안화하지 않습니다.

Actions → Naver Blog Drafts → Run workflow에서 수동 실행할 수 있습니다.

## 생성되는 초안

`Naver_Drafts/날짜_제목/` 아래에 다음 파일이 생성됩니다.

- `01_네이버_원고.html`
- `02_네이버_원고.txt`
- `03_이미지_목록.txt`
- `04_발행_체크리스트.txt`
- `metadata.json`
- `images/`

## 네이버 편집기 입력

GitHub Actions는 사용자의 로컬 PC에서 로그인된 네이버 브라우저를 조작할 수 없습니다. 이 프로젝트는 클라우드에서 초안을 생성합니다. 사용자는 저장소에서 원고와 이미지를 내려받아 네이버 에디터에 반영하고 최종 검토 후 직접 발행합니다.

`01_네이버_원고.html`은 브라우저 미리보기와 복사용 HTML 원고입니다. HTML 미리보기의 CSS가 네이버 편집기에 그대로 복사되는 것은 아니므로, 실제 네이버 편집기에 붙여넣은 뒤 제목·표·이미지·코드 이미지의 모양을 확인해야 합니다. 토글은 네이버 편집기 호환성을 위해 펼친 본문으로 변환됩니다.

## 코드 이미지 한글 폰트

GitHub Actions는 코드 이미지 생성 전에 `fonts-noto-cjk`를 설치합니다. 로컬 실행 시에는 Noto Sans Mono CJK KR, NanumGothicCoding, Malgun Gothic 등 설치된 한국어 지원 폰트를 자동 탐색합니다. 필요하면 `CODE_FONT_PATH` 환경 변수로 폰트 파일 경로를 지정할 수 있습니다.

## 설정 옵션

| 변수 | 기본값 | 설명 |
|---|---|---|
| `NOTION_PROPERTY_TITLE` | `제목` | 제목 속성 |
| `NOTION_PROPERTY_DATE` | `날짜` | 날짜 속성 |
| `NOTION_PROPERTY_MEMO` | `간단메모` | 메모 속성 |
| `NOTION_PROPERTY_TAGS` | `태그` | 태그 속성 |
| `UPDATE_EXISTING_DRAFTS` | `false` | 이미 처리한 미발행 초안 업데이트 허용 |
| `MAX_DOWNLOAD_MB` | `50` | 파일당 다운로드 제한 |

## 처리 이력 초기화

모든 Notion 페이지를 새 초안으로 다시 처리해야 할 때만 다음 내용으로
`Naver_Drafts/processed_pages.json`을 초기화하세요.

```json
{
  "version": 1,
  "pages": {}
}
```

처리 이력을 초기화하면 오늘 날짜에 해당하는 페이지가 다음 실행에서 다시 초안으로 생성됩니다.

## 네이버 블로그에 붙여넣기

- `02_네이버_본문.txt`는 서식이 없는 순수 텍스트입니다. GitHub 웹 미리보기에서 복사하지 말고, 파일을 PC로 다운로드해 메모장/일반 텍스트 편집기에서 복사하세요.
- 네이버 편집기에 검은 배경/흰 글씨가 남으면 글 전체를 선택해 글자색을 검정, 글자 배경색을 없음으로 설정하세요. 이 효과는 TXT 파일에 들어 있는 서식이 아닙니다.
- Notion 이미지는 GitHub Actions가 게시글의 `images/` 폴더로 자동 다운로드합니다. 사진을 하나씩 GitHub에서 받을 필요는 없습니다.
- 네이버 사진 첨부 창에서 여러 장을 한 번에 선택할 수 있으며, 레이아웃은 `개별 사진`을 선택하세요. 본문 중간에 들어가는 사진은 원고의 이미지 위치 표시에 맞춰 배치합니다.
- 코드 이미지는 흰 배경과 검은 글자로 생성합니다.
